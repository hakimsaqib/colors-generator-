Color Changer Game 🎨
A simple and interactive Color Changer Game built using HTML, CSS, and JavaScript.
This project changes colors dynamically and provides a fun way to practice DOM manipulation and JavaScript event handling.
🚀 Features


Dynamic background color changing


Random color generation


Clean and responsive UI


Smooth user interaction


Beginner-friendly JavaScript project


🛠️ Technologies Used
